# jstash

[jstash Apps](https://jstash.app/apps/) gives each signed-in user of your web app their own private JSON documents. Keep the login you already have (Clerk, Supabase Auth, Firebase Auth or Sign In With Google). Your page sends the person’s login token with plain `fetch`, and jstash checks it. No backend, no database and no security rules to write.

- **Try it:** [Cloud Notes demo](https://jstash.app/demo/). Sign in with Google, save a note, open it on your phone.
- **Examples:** [jstash-examples](https://github.com/jstash-app/jstash-examples) for Clerk + Vite, Sign In With Google (plain HTML) and Supabase + Vite.
- **Docs:** [Apps guide](https://jstash.app/docs/apps/) · [Markdown reference for coding agents](https://jstash.app/docs/apps.md) · [llms.txt](https://jstash.app/llms.txt)
- **Bins:** save a JSON document with one request and get a URL. [Docs](https://jstash.app/docs/).

Free includes 1 app with up to 100 users. No card. [Pricing](https://jstash.app/pricing/).
